## Working rules

- Keep all committed material safe for public disclosure.
- Never add private addresses, internal DNS names, credentials, secret-store
  metadata, device identifiers, customer data, or non-public topology.
- Prefer sanitized examples and clearly marked placeholders.
- Keep changes concise and document validation appropriate to files introduced.
- Use GitHub pull requests against `main`.
